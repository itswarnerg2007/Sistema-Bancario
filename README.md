# Cajero Automático en Python

Aplicación de consola desarrollada en Python que simula el funcionamiento básico de un cajero automático. Permite consultar el saldo, realizar depósitos y retiros mediante un menú interactivo.

## Funcionalidades

- Consultar saldo.
- Depositar dinero.
- Retirar dinero.
- Validar fondos suficientes antes de retirar.
- Menú interactivo con opción para salir del programa.

## Tecnologías

- Python 3

## Conceptos aplicados

- Variables
- Condicionales (`if`, `elif`, `else`)
- Ciclos (`while`)
- Entrada y salida de datos (`input` y `print`)
- Operadores aritméticos y de comparación
